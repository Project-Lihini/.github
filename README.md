# Project Lihini Github Profile

![Poster](./assets/Cover.png)

Project Lihini is an open-source, crowd-sourced weather monitoring platform designed to address the lack of flexible, accessible, and community-driven weather data. While modern society uses various sophisticated technologies like satellites and radar for weather monitoring, these systems are often complex, costly, and operated by specialized entities like government agencies or large organizations. This model limits public participation in the data collection process, creating a gap for individuals and communities who wish to contribute to or access hyper-local weather information. The project aims to fill this gap by providing a comprehensive, end-to-end solution that includes open-source hardware designs, software, and a public data repository.

The vision for Project Lihini is to create a global, scalable ecosystem where individuals and communities can collect, share, and analyze local environmental data. The mission is to make environmental data accessible to everyone by providing fully open-source hardware designs, software, and a public data repository. This approach fosters a global community where people can openly contribute, learn, and collaborate. By focusing on openness, collaboration, education, and accessibility, the project aims to empower people to become active participants in weather monitoring, rather than just passive consumers of data. The platform's values ensure a supportive and respectful environment for all contributors, regardless of skill level. The project’s scope is focused exclusively on weather monitoring, including low-cost sensor arrays for temperature, humidity, pressure, wind, and rainfall.

The technical architecture of Project Lihini is multi-tiered, consisting of a Device Layer for data sensing, a Backend Layer for data processing and storage, and a Frontend Layer for data visualization. The hardware will be a low-cost device using microcontrollers like ESP32 or ESP8266, while the backend will utilize an MQTT broker and a time-series database for efficient data management. The web frontend will provide a user-friendly interface to display both real-time and historical weather data. By democratizing access to crucial environmental data, Project Lihini has the potential to improve disaster preparedness, enhance agricultural productivity, support climate change research, and promote citizen science and education.
